أردتُ موقعًا شخصيًا يتصرف مثل المنتجات التي أبنيها: سريع، ويُقرأ جيدًا بالعربية، وصادق في ما يعرضه.

## كود واحد ولغتان

الموقع مشروع Next.js بنظام App Router مع `next-intl`. كل صفحة موجودة على `/en` و`/ar`. العربية ليست ترجمة تُضاف لاحقًا — التخطيطات تستخدم خصائص CSS المنطقية (`margin-inline-start` و`text-align: start`) فتنقلب المكوّنات نفسها بشكل صحيح في الاتجاه من اليمين إلى اليسار.

## واجهة رئيسية تحترم الجهاز

تعرض الواجهة الرئيسية حقل جسيمات يتفاعل مع المؤشر، مع لابتوب وهاتف عائمين يعرضان لقطات حقيقية من المشاريع. بُنيت بـ three.js و React Three Fiber وتُحمَّل بشكل كسول.

- عند تفعيل `prefers-reduced-motion` أو غياب WebGL يُتخطى المشهد ثلاثي الأبعاد ويظهر نموذج CSS بدلًا منه.
- على الشاشات الضيقة يُعرض حقل الجسيمات فقط.
- يتوقف الرسم عند خروج الواجهة من الشاشة أو إخفاء التبويب.

## المحتوى كبيانات مكتوبة بأنواع

كل دراسة حالة كائن TypeScript بنصوص إنجليزية وعربية متجاورة. إضافة مشروع تعني إضافة ملف واحد — وتلتقطه صفحة الأعمال وصفحة دراسة الحالة ولوحة الأوامر وخريطة الموقع تلقائيًا.

## تفاصيل صغيرة مهمة

لوحة أوامر ⌘K، ومظهر يُضبط قبل أول رسم لتفادي الوميض، وبيانات وصفية لكل صفحة مع بدائل `hreflang`، ونموذج تواصل يُرسل عبر Server Action فلا تصل أي مفاتيح إلى المتصفح.
